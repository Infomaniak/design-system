# Web

## EsdsIconComponent

### Installation

```shell
yarn add @infomaniak-design-system/esds-icon
```

### Initialization

The icon component needs to be initialized before it can be rendered:

```ts
import { EsdsIconComponent } from '@infomaniak-design-system/esds-icon';

EsdsIconComponent.init();
```

This allows defining the API proxy to fetch the icons and registering the custom element.

You should put it in your `main.ts` or `app.ts` file.

### Usage

```html
<esds-icon
  style="font-size: var(--esds-icon-size-md); color: var(--esds-color-text-primary)"
  name="esds:home"
></esds-icon>
```

#### Styling

The icon may be styled using the following CSS properties:

- `color`: to set the icon's color
- `font-size`: to set the icon's size

    <td>The name of the icon to display.</td>

  <tr>
    <td>mode</td>
    <td>
      <code>EsdsIconComponentMode</code>
    </td>
    <td>
      The <code>mode</code> to apply:
      <ul>
        <li>
          <code>svg</code>: injects the svg as direct &lt;svg&gt; child of this component.
        </li>
        <li>
          <code>bg</code>: uses the svg as "background-image" of this component.
        </li>
        <li>
          <code>mask</code>: injects the svg as "mask-image" of this component: this is useful to
          apply color to the svg.
        </li>
      </ul>
    </td>
  </tr>
  <tr>
    <td>inline</td>
    <td>
      <code>boolean</code>
    </td>
    <td>
      Adding <code>inline</code> property to the icon component is identical to setting{' '}
      <code>style="vertical-align: -0.125em"</code>. This is useful to correct the icon's alignment.
    </td>
  </tr>
  <tr>
    <td>nolazy</td>
    <td>
      <code>boolean</code>
    </td>
    <td>
      By default, icons are rendered only when visible to the visitor. You can opt out of this
      behavior by adding the <code>nolazy</code> attribute.
    </td>
  </tr>
