During the SVG build process, all stroke-widths are replaced with a relative formula and the `vector-effect="non-scaling-stroke"` attribute is added so stroke width stays consistent regardless of scaling:

```
stroke-width="calc((1em / 32) + 1px)"
vector-effect="non-scaling-stroke"
```

This gives the following approximate stroke-widths:

- **24px** icon → **1.75px** stroke-width
- **32px** icon → **2px** stroke-width
- **40px** icon → **2.25px** stroke-width
- ...

See the [implementation](https://github.com/Infomaniak/design-system/blob/develop/packages/assets/images/svg/scripts/shared/svg/iconify/build-svg-set-from-svg-directory/apply-optical-sizes.ts) for more details.

> ⚠️ **Note:** Mobile platforms (iOS, Android) handle icon sizing differently. This approach is specific to the **web** implementation.
