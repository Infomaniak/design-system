# Design Tokens - AI & LLMs

Use the <a href="./?path=/docs/ai-llms--docs">AI &amp; LLMs</a> resources (`DESIGN.md`, `llms.txt` and `llms-full.txt`) to provide design system context to your AI agent or LLM.
