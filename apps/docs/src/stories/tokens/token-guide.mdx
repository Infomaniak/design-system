## Token Architecture

Our token system follows the Design Tokens Community Group (DTCG) standard with a three-tier architecture:

- <a href="/?path=/docs/design-tokens-t1--docs">T1 Primitive tokens</a> for foundational tokens
  values
- <a href="/?path=/docs/design-tokens-t2--docs">T2 Semantic tokens</a> for semantic abstraction
  tokens
- <a href="/?path=/docs/design-tokens-t3--docs">T3 Component tokens</a> for component-specific
  tokens

## How It Works

### Token Resolution Chain

Token values reference each other in a hierarchy, ensuring consistency across the system:

```
T3-Component  →  button.background.error
                    ↓
T2-Semantic   →  color.background.error.default
                    ↓
T1-Primitive  →  color.red.600 (#E21C40)
```

When a primitive value changes, every token referencing it updates automatically.

### Context Overrides with Modifiers

Modifiers provide alternative values for T2 or T3 tokens to adapt to specific contexts. When you apply modifiers, they replace the default values in the resolution chain.

**Available modifiers:**

- **Theme**: `light`, `dark`
- **Product**: `infomaniak`, `euria`, `swisstransfer`, ...

**Example: Euria dark mode**

Let's trace how a button's background resolves with multiple modifiers:

**Without modifiers (default):**

```
T3: button.background.default → T2: color.background.brand.default → T1: color.sky.700 (#0098FF)
```

**With `data-esds-product="euria"`:**

```
T3: button.background.default → T2: color.background.brand.default → T1: color.ocean.700 (#0064F0)
                                              ↑
                              Modifier overrides semantic token
```

**With `data-esds-product="euria"` and `data-esds-theme="dark"`:**

```
T3: button.background.default → T2: color.background.brand.default → T1: color.ocean.400 (#48BFFF)
                                              ↑
                    Both modifiers combine for final color.ocean.400 value
```

Apply modifiers using data attributes:

```html
<div
  data-esds-product="euria"
  data-esds-theme="dark"
>
  <button style="background: var(--esds-color-background-brand-default)">Click me!</button>
</div>
```

## Consuming Tokens

### Web

#### Install via npm

```bash
npm install @infomaniak-design-system/tokens
```

#### CSS Variables

Import the base tokens and any modifiers you need:

```css
/* Base tokens (required) */
@import '@infomaniak-design-system/tokens/css/tokens.root.css';

/* Theme modifiers */
@import '@infomaniak-design-system/tokens/css/modifiers/theme/light.root.css';
@import '@infomaniak-design-system/tokens/css/modifiers/theme/dark.root.css';
```

Apply modifiers using data attributes:

```html
<button
  data-esds-button-size="small"
  data-esds-button-type="primary"
>
  Click me!
</button>
```

#### Tailwind CSS

If you're using Tailwind, import our theme extension:

```css
/* src/styles/tailwind.css */
@import 'tailwindcss';
@import '@infomaniak-design-system/tokens/tailwind.css';
```

Tokens automatically map to Tailwind utilities:

```html
<!-- index.html -->
<link
  rel="stylesheet"
  href="src/styles/tailwind.css"
/>

/* ... */

<button class="bg-yellow-500">Click Me!</button>
```
