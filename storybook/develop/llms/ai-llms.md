# AI & LLMs

> The design system publishes machine-readable resources so AI agents, coding assistants and LLMs can consume accurate,...

The design system publishes machine-readable resources so AI agents, coding assistants and LLMs
can consume accurate, up-to-date documentation:

- [llms.txt](../llms.txt) — lightweight index and router: global coding rules plus categorized
  links to every documentation page. Start here for agent discovery.
- [llms-full.txt](../llms-full.txt) — the complete documentation in a single file (includes
  DESIGN.md), for one-shot ingestion (Cursor `@Docs`, RAG pipelines, chat uploads).
- [DESIGN.md](../DESIGN.md) — machine-readable token reference generated from our token
  definitions, in a format optimized for AI consumption.
