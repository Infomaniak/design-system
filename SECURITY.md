# Security Policy

## Supported Versions

This repository publishes two npm packages: [`@infomaniak-design-system/tokens`](https://www.npmjs.com/package/@infomaniak-design-system/tokens) and [`@infomaniak-design-system/components`](https://www.npmjs.com/package/@infomaniak-design-system/components).

Security fixes are only released in the latest published version of each package. Please make sure you are using the most recent release before reporting a vulnerability.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report them privately through [GitHub's Private Vulnerability Reporting](https://github.com/Infomaniak/design-system/security/advisories/new).

When reporting, please include:

- The affected package(s) and version(s)
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept, if possible

### What to expect

- We will acknowledge your report within 2 weeks.
- If the vulnerability is accepted, we will prepare a fix and publish a security advisory, keeping you informed along the way.
- If the vulnerability is declined, we will explain why.

## Scope

Everything in this repository is in scope: the published npm packages, the documentation site, and the build and CI tooling alike. We triage each report individually and decide how to address it based on its severity and impact.
