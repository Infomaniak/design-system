Add `kbd-size` modifiers (`medium`, `large`) to scale the `esds-kbd` key cap — typography, padding and gap — applied with the new `data-esds-kbd-size` attribute. `medium` is the default and can also be set explicitly. The default key gap is tightened from 4px to 2px.
