Add `kbd-size` modifiers (`extra-small`, `small`, `medium`, `large`) to scale the `esds-kbd` key cap — typography, padding, gap and radius — to the extra-small, small, medium and large body sizes, applied with the new `data-esds-kbd-size` attribute. `extra-small` is the default and can also be set explicitly. When a keyboard shortcut sits inside a button, set the same size on both elements so the shortcut shares the button typography.
