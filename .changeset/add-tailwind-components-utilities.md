Separate Tailwind CSS v4 integration: the `tailwind.css` stylesheet maps all design tokens to Tailwind theme namespaces (`--color-*`, `--font-*`, `--text-*`, `--font-weight-*`, `--tracking-*`, `--radius-*`, `--blur-*`) via `@theme inline`. New `esds-heading-*` and `esds-body-*` utility classes are also available to apply typography text styles directly through Tailwind.
