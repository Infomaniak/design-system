Add the `esds-badge` web component and its design tokens.

- New `esds-badge` component that renders a compact status badge around its slotted content (`role="status"`).
- New `badge` component tokens (size, padding, radius, colors, font) and `badge-type` modifiers (`primary`, `neutral`, `destructive`).
- Added a `6px` step to the primitive size scale for the badge dot.
