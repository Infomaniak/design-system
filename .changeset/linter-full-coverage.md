Full rule coverage joins the linter (18 read-only rules). Errors: stroke weights set with raw values and effects configured with raw settings instead of an effect style or variable (`unbound-effect`), TEXT nodes styled by hand (`no-text-style`), and drawn containers named exactly like a kit icon (`icon-as-frame`). Warnings: hand-set opacity below 100% over a colored fill (`opacity-over-color`), effect/text styles local to the file instead of published (`local-effect-style`, `local-text-style`), nodes overriding a published text style's size, weight, decoration or line height (`style-override`), non-default blend modes (`blend-mode`), brand/dataviz tokens bound without their published `@root` variant (`dataviz-brand-root`), bindings resolved to variables from collections local to the file (`local-collection` — also fires inside the design-system source file) and local components duplicating a kit icon (`local-duplicate`). The icon name match is exact against an icon inventory generated at build time from the svg-assets package, and the plugin now uses the official `@figma/plugin-typings` for its Figma API surface.
