Added new semantic feedback color tokens:

- New `information` and `neutral` color groups across backgrounds (dim1, dim2, dim3), foregrounds, borders, and interaction states, available in both light and dark themes.
- New `dim3` (subtle) background variants for the `success`, `warning`, and `error` feedback colors.
- Aligned the dark theme error feedback background with the light theme for visual consistency.
