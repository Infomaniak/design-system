# InjectionContext

An `InjectionContext` is a way to pass data to a component tree.

## Producer perspective

The producer is responsible for creating the `InjectionContext` and passing it to the children.

### Set the root context

The **root** `InjectionContext` is available globally. It is the terminal point when resolving a value.

```ts
// exemple: setup the IconifyApi to point on the preprod environment
InjectionContext.root = new InjectionContext([
  ICONIFY_API.define(
    new IconifyApi({
      resources: ['https://iconify.preprod.dev.infomaniak.ch'],
    }),
  ),
]);
```

It's optional, but you probably want to define it.

### Set a context starting from an Element

An `InjectionContext` can be applied to any DOM element:

The element itself, as well as every child (direct or indirect) of it, will inherit of this context.

Multiple `InjectionContext` can be applied to different nodes in the DOM tree:
a _key_ (`InjectionContext.get(node, key)`) is resolved exploring the stating _node_ itself, and each parent of it (or `InjectionContext.root` when `document` is reached),
until a context with the matching key is found.

#### Examples

> NOTE: in the following examples, we'll assume that the DS exports a `LOCALE` of type `InjectableValue`.

##### React

```tsx
function MyComponent() {
  const ctx = new InjectionContext([LOCALE.define('fr-FR')]);

  return (
    <div data-inject={ctx.id}>
      {/* every child will inherit the context of the parent */}
      <span>
        <esds-component />
      </span>
    </div>
  );
}
```

##### Angular

```ts
@Component({
  selector: 'my-component',
  // ...
})
export class ConsumerComponent {
  readonly ctx = new InjectionContext([LOCALE.define('fr-FR')]);
}
```

```html
<div [attr.data-inject]="ctx.id">
  <!-- every child will inherit the context of the parent -->
  <span>
    <esds-component />
  </span>
</div>
```

##### Lit

```ts
@customElement('my-component')
export class ConsumerComponent extends LitElement {
  readonly ctx = new InjectionContext([LOCALE.define('fr-FR')]);

  override render(): TemplateResult {
    return html`
      <div data-inject="${this.ctx.id}">
        <span>
          <esds-component />
        </span>
      </div>
    `;
  }
}
```

## Consumer perspective (DS team)

The consumer is responsible for consuming the `InjectionContext`.

### Create an `InjectableValue`

The consummer starts by creating a `InjectableValue`: it is used by the **Producer** to define injectable values, and by the **Consumer** to read them.

```ts
const LOCALE = new InjectableValue('locale');
```

### Read/Observe an `InjectableValue`

```ts
@customElement('esds-component')
export class ConsumerComponent extends LitElement {
  readonly #locale: Signal<string> = hostInject(this, LOCALE, (): string => navigator.language);

  override render(): TemplateResult {
    return html`locale: ${this.#locale.get()}`;
  }
}
```

## Documentation

### class `InjectableValue`

This class is used to define injectable values with unique symbolic keys used by `InjectionContext`.

```ts
class InjectableValue<GValue> {
  constructor(name: string);

  get key(): symbol;

  /**
   * Creates an `InjectedEntry` to use when constructing a new `InjectionContext`.
   */
  define(value: GValue): InjectedEntry<GValue>;
}
```

### class `InjectionContext`

Represents a context for dependency injection. It allows for storing and retrieving values
associated with symbols, providing a mechanism for scoped dependency injection.

```ts
class InjectionContext {
  static root: InjectionContext | undefined;
  static readonly attributeName: 'data-inject';

  /**
   * Retrieves a value associated with the specified key from the nearest context within the provided node's hierarchy.
   */
  static get<GValue>(source: Node, key: InjectedKeyLike): GValue | undefined;

  constructor(entries?: InjectionContextEntries);

  get id(): string;

  /* MAP LIKE */
  get size(): number;
  has(key: InjectedKeyLike): boolean;
  get<GValue>(key: InjectedKeyLike): GValue | undefined;
  keys(): MapIterator<symbol>;
  values(): MapIterator<unknown>;
  entries(): MapIterator<InjectedEntry<unknown>>;
  [Symbol.iterator](): MapIterator<InjectedEntry<unknown>>;
}
```
