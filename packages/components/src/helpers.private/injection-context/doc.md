## InjectionContext

### Create an `Injectable`

```ts
const locale = new Injectable('locale');
```

### Init the _root_ `InjectionContext`

```ts
InjectionContext.root = new InjectionContext([locale.inject('en-US')]);
```

#### Consume the `InjectionContext` (for the DS components)

```ts
InjectionContext.get(document, locale); // 'en-US'
```

### Create a new `InjectionContext`

> Notes:
>
> - `ConsumerComponent`: is generated by the consumer (the dev consuming the DS components)
> - `esds-component`: is a DS component

#### React

##### ConsumerComponent

```tsx
function ConsumerComponent() {
  const myRef = useRef(null);

  const ctx = new InjectionContext([locale.use('fr-FR')]);

  return (
    <div id={ctx.id}>
      {/* every child will inherit the context of the parent*/}
      <esds-component />
    </div>
  );
}
```

##### esds-component

function EsdsComponent() {

#### Angular

##### consumer-component

```ts
@Component({
  selector: 'consumer-component',
  // ...
})
export class ConsumerComponent {
  readonly ctx = new InjectionContext([locale.use('fr-FR')]);
}
```

```html
<div [id]="ctx.id">
  <!-- every child will inherit the context of the parent -->
  <esds-component />
</div>
```

#### Lit

##### consumer-component

```ts
@customElement('consumer-component')
export class ConsumerComponent extends LitElement {
  readonly ctx = new InjectionContext([locale.use('fr-FR')]);

  override render(): TemplateResult {
    return html`<div id="${this.ctx.id}"></div>`;
  }
}
```

##### esds-component

```ts
@customElement('esds-component')
export class EsdsComponent extends LitElement {
  constructor() {
    super();
    console.log(InjectionContext.get(this, locale)); // fr-FR
  }
}
```

> NOTE: `this` refers to the current component or any children of it.
