## Usage

Import and register the custom attribute `esds-link`:

```ts
import { EsdsLinkAttr } from '@infomaniak-design-system/components';

EsdsLinkAttr.define();
```

```html
<a
  esds-link
  href="https://example.com"
>
  Link text
</a>
```

## Description

Adding the custom attribute `esds-link` to an `<a>` element, applies the `esds-link` styles to this element.

> [!NOTE]
> The `<a>` element may be used as any other `<a>` element.
